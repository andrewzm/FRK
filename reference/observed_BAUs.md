# Observed (or unobserved) BAUs

Computes the indices (a numeric vector) of the observed (or unobserved)
BAUs

## Usage

``` r
observed_BAUs(object)

unobserved_BAUs(object)

# S4 method for class 'SRE'
observed_BAUs(object)

# S4 method for class 'SRE'
unobserved_BAUs(object)
```

## Arguments

- object:

  object of class `SRE`
