# Americium soil data

Americium (Am) concentrations in a spatial domain immediately
surrounding the location at which nuclear devices were detonated at Area
13 of the Nevada Test Site, between 1954 and 1963.

## Usage

``` r
Am_data
```

## Format

A data frame with 212 rows and 3 variables:

- Easting:

  Easting in metres

- Northing:

  Northing in metres

- Am:

  Americium concentration in 1000 counts per minute

## References

Paul R, Cressie N (2011). “Lognormal block kriging for contaminated
soil.” European Journal of Soil Science, 62, 337–345.
