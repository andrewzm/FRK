# Retrieve fit information for SRE model

Takes an object of class `SRE` and returns a list containing all the
relevant information on parameter estimation

## Usage

``` r
info_fit(object)

# S4 method for class 'SRE'
info_fit(object)
```

## Arguments

- object:

  object of class `SRE`
